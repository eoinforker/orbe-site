This is Orbe's public website, served by GitHub Pages. Every tool runs in your browser on Orbe's own engine, and nothing you type or upload leaves your device. Every creator, show, brand and figure on the site is made up and labelled as such.

## The products

- **[Rate my work](https://eoinforker.github.io/orbe-site/products/rate/):** the Orbe Rating from an export you already have, against creators your size. Zero is typical.
- **[Podcasts](https://eoinforker.github.io/orbe-site/products/podcasts/):** measurement set-up, a feed check, a sample dashboard and a plausibility check for download claims.
- **[Sponsorships](https://eoinforker.github.io/orbe-site/products/sponsorships/):** a price for a slot from what your work actually delivered, with the reasons.
- **[Selling](https://eoinforker.github.io/orbe-site/products/selling/):** an indicative value, with every factor that moved it, and the fees on any price.
- **[Diligence](https://eoinforker.github.io/orbe-site/products/diligence/):** the report a buyer reads before an offer, on made-up records.
- **[Roster](https://eoinforker.github.io/orbe-site/products/roster/):** a manager's whole roster, each creator rated against their own size.

Every page says what works today and what switches on with the Orbe API. The [brand book](https://eoinforker.github.io/orbe-site/brand/) shows the system the site is built from.

## About this repository

It is generated from Orbe's main repository by `scripts/publish-site.sh`, which replaces everything here except this README. Please don't edit the site here: change it in the main repository and publish again.
