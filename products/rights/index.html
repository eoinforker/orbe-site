Orbe Rights Record v0

Free for creators, for good. Your deals are yours: keep them, take them with you, hand them to a manager or a lawyer. The record is the same open format brands use, so both sides can read the same thing.

Each deal is an event you sign, chained by SHA-256, so nobody can quietly change a date or a fee later. With the API, the brand signs the same record and you get a note before each right ends.

Everything here runs on this device. Nothing you add is sent anywhere.

The record

Orbe Rights Record v0

Every change is an event: who did it, when, and the SHA-256 hash of the event before. Change one fee anywhere and every hash after it stops matching. Revoking is an event too, so nothing is ever edited away.

The format is open: works, chain of title, the creator's consent scopes, usage grants and their events, in plain JSON. Anyone can read or write it without Orbe.

Imported files are read on this device and never sent anywhere.
